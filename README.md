#Blinky Board
I was today years old when I found out the red ghost in pac-man was named blinky, so this is why I made a blinky board THAT LOOKS LIKE BLINKY!! Blinky has 10 LEDs on him, 2 for his eyes and the other 8 for his mouth (im not really sure that the ghosts actually have mouths in pacman but lets pretend lol)

#Why did I make this?
Realistically this project doesn't have some meaningful earth shattering purpose, I just started it because I wanted a project to finish the very minimal amount of fallout debt I had left, all while giving me some review of how a 555 timer works (I did not understand that unit from my computer engineering class).
Usually a blinky is someone's first hardware project but it's actually my third. But hey its never too late to make one yk?
